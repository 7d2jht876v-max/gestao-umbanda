Gestão Umbanda
Notebook como servidor · versão 1.0

Esta instalação mantém as telas do aplicativo e troca o Supabase por um banco de dados no notebook. O iPhone usa a mesma rede Wi-Fi. Os dados antigos não são apagados e as senhas antigas não são transferidas.

1. Preparar o notebook Windows

  1. Baixe o ZIP no notebook. Clique com o botão direito e escolha Extrair tudo. Guarde a pasta em um local fixo, por exemplo Documentos\Gestao-Umbanda. Não execute de dentro do ZIP.
  2. Se não houver Python, instale Python 3.11 ou superior pelo site oficial do Python, incluindo o launcher py. Não precisa comprar programas.
  3. Abra INSTALAR.bat. Ele cria um ambiente próprio, instala a dependência de certificados e gera um certificado exclusivo para sua rede. A primeira instalação precisa de internet.
  4. O instalador pergunta se você deseja confiar no certificado público no seu usuário do Windows. Leia a mensagem e confirme somente se estiver executando a sua cópia desta pasta. Não ignore alertas HTTPS no navegador.
  5. Abra INICIAR.bat. Mantenha a janela aberta. Se o Windows perguntar sobre o firewall, permita Python somente em redes privadas. Não libere em redes públicas.

2. Criar o administrador

  1. No notebook, abra https://localhost:8787/configurar.
  2. Copie o código de configuração da janela do servidor. Informe seu e-mail e crie uma senha exclusiva com pelo menos 12 caracteres. A conta inicial só pode ser criada no próprio notebook.
  3. Entre com essa conta. Não há senha padrão. Guarde a senha em seu gerenciador de senhas.

3. Transferir os cadastros

  1. No mesmo navegador e perfil usados para cadastrar os dados antigos, abra Exportar dados para o notebook. Essa página funciona sem consultar o Supabase.
  2. Clique em Baixar dados deste aparelho. Os dados continuam no aplicativo antigo.
  3. Na configuração do servidor, selecione o arquivo JSON e clique em Importar e preservar registros. Diferenças com o mesmo identificador são mantidas em cópias. O arquivo original também fica preservado na pasta dados.
  4. Se o iPhone tiver cadastros ainda não enviados, exporte também pelo Safari e importe esse segundo arquivo no notebook. O app instalado no iPhone pode ter armazenamento separado do Safari; verifique a contagem exportada. Se os registros não aparecerem, mantenha o app instalado e solicite ajuda para exportar os dados daquele armazenamento.
  5. Abra o Gestão Umbanda no servidor e confira os cadastros, financeiro, camarinhas, fotos e radiestesia. Use Publicar dados individuais dos médiuns para preparar as áreas pessoais.

4. Conectar o iPhone com HTTPS

É necessário confiar no certificado local, uma única vez por instalação. Esse certificado é exclusivo do seu notebook. Instale somente o arquivo público indicado abaixo; nunca envie arquivos terminados em -key.pem.

  1. Copie dados\certificados\CA-Templo-Xango.cer para o iPhone, por exemplo pelo iCloud Drive. Abra o arquivo no Safari ou Arquivos. Se não iniciar a instalação, compartilhe-o para o Safari.
  2. Em Ajustes → Geral → VPN e Gerenciamento de Dispositivo, instale o perfil do certificado Templo Xango - Notebook local. O iPhone pode pedir o seu código de desbloqueio; digite somente no próprio aparelho.
  3. Em Ajustes → Geral → Sobre → Ajustes de Confiança de Certificados, ative a confiança total apenas nesse certificado. Os nomes dos menus podem variar conforme a versão do iOS.
  4. Conecte notebook e iPhone à mesma rede Wi-Fi. No Safari, abra o endereço https://IP-DO-NOTEBOOK:8787/ mostrado em INICIAR.bat. Não use o endereço do GitHub para acessar este servidor.
  5. Entre com a conta criada no notebook. Para o administrador consultar tudo nos dois aparelhos, use a mesma conta. Para um médium, crie uma conta própria e publique os seus dados individuais.
  6. No Safari, use Compartilhar → Adicionar à Tela de Início. Mantenha o app antigo até conferir a transferência completa.

Se houver alerta de certificado, não avance ignorando o aviso. Confira a instalação do certificado e o endereço. Se o IP do notebook mudou, feche o servidor e execute INSTALAR.bat novamente; a autoridade local será mantida e o certificado do servidor será renovado para o IP atual. Uma reserva de IP no roteador evita mudanças frequentes.

5. Uso e backup

  • O servidor precisa ficar ligado, com a janela aberta e sem suspensão. Durante o uso, mantenha o notebook na tomada. Fora da mesma rede Wi-Fi, não há acesso nesta versão.
  • As alterações são salvas no navegador e enviadas automaticamente quando há conexão. O envio usa partes de até 192 KiB e retoma as partes pendentes; registros iguais não são reenviados. A primeira transferência pode ser maior por incluir os anexos existentes.
  • O servidor confirma alterações em transações curtas e verifica a versão para evitar sobrescrever edições feitas no outro aparelho. Aguarde a confirmação de sincronização antes de fechar o navegador.
  • O arquivo principal fica em dados\templo.sqlite3. Há backups diários antes da sincronização e antes de cada importação em dados\backups. Copie regularmente a pasta dados para um pendrive protegido. Ela contém dados pessoais, financeiros, prontuários e senhas protegidas.
  • Para uma cópia completa manual, encerre o servidor com Ctrl+C e copie a pasta dados inteira. Guarde também esta pasta do programa. Para restaurar, encerre o servidor, preserve a pasta atual e substitua os arquivos apenas por uma cópia completa e conhecida. Não misture arquivos SQLite de cópias diferentes.
  • Não encaminhe portas do roteador e não exponha esta versão à internet. Não precisa contratar plano ou aumentar a cobrança do Supabase para usar o servidor local.

O que ainda depende do seu notebook

A instalação, a liberação do firewall e a confiança do certificado no iPhone precisam ser feitas nos aparelhos. O pacote foi testado em ambiente Linux; a abertura dos arquivos BAT no Windows e a instalação do certificado no iPhone devem ser conferidas na sua rede antes de considerar a migração concluída.

Referência da Apple: Confiar em perfis de certificado instalados manualmente.
