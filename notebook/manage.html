Gestão Umbanda · Servidor do notebook

O notebook precisa ficar ligado. O iPhone deve estar na mesma rede Wi-Fi.

Verificando servidor…

1. Criar administrador

Faça esta etapa no notebook, em https://localhost:8787/configurar. Use o código exibido na janela do servidor.

Entrar como administrador

2. Transferir os dados existentes

No notebook, abra a página de exportação do aplicativo antigo, no mesmo navegador e perfil em que fazia os cadastros. Baixe o arquivo e selecione-o abaixo. Se houver dados diferentes no iPhone, exporte-os também e importe depois; as diferenças serão preservadas em cópias.

Exportar do aplicativo antigo

3. Backup

O servidor cria um backup diário antes da sincronização e outro antes de cada importação, na pasta dados/backups. Copie os backups para um pendrive ou outro local seguro: eles contêm os cadastros do templo.

4. Acessos dos médiuns

As contas do Supabase não são copiadas. Crie os acessos aqui ou publique os dados individuais e use “Criar acessos dos médiuns” no aplicativo. As contas existentes nunca são redefinidas automaticamente.

Recuperar acesso de uma conta

Use somente para uma conta já cadastrada. A redefinição mantém os registros e encerra as sessões dessa conta.

Abrir Gestão Umbanda

Conectar o iPhone

Use o endereço https://IP-DO-NOTEBOOK:8787/ exibido na janela do servidor. O endereço antigo do GitHub não conecta ao notebook.

Primeiro instale o certificado público CA-Templo-Xango.cer seguindo o arquivo LEIA-PRIMEIRO.html. Não ignore avisos de segurança. Mudanças no endereço IP exigem gerar novamente o certificado do servidor.

Fora da mesma rede Wi-Fi, esta versão não fica disponível. Não configure encaminhamento de portas no roteador.
